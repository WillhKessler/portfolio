In this tutorial we will be utilizing Github Pages to host a simple 'Library of Things' that small organizations or individuals can use to lend items. In this example, we will use the 'North Cascades Gear Library' which is a free Library of Things for bikepacking and camping equipment based in Bellingham, WA. 
The most complicated part of this tutorial for the lay person is likely going to be building comfort with Github. The platform has a plethora of features that we won't touch on here, but think of it simply as as the place that your website, and the simple code that powers it lives.
